# 原生口语回归检查

本组检查使用临时目录、协议替身与模拟识别结果，不读取模型、用户身份或正式学习记录。

Java协议检查需要JDK 17或更新版本，以及项目使用的官方 `org.json:json:20240303` jar：

```sh
python native/tests/run-tests.py --jdk /path/to/jdk --json-jar /path/to/json-20240303.jar
node --experimental-vm-modules native/tests/local-client.test.mjs
```

Java检查覆盖陪练、模拟和评价的短任务请求、MCP实际发言证据、未读任务的等待上限、题卡读取后的回复等待、没有start的空stop、平台错误提示和密钥脱敏。替身解码器不证明真实音频播放正常。

JS检查覆盖已经完成的识别任务立即取回、进行中的任务继续轮询、识别失败时保留原声且不提交考官，以及实际文字随题卡提交并得到回复。

实际平台仍需额外联调：记录“录音停止→识别完成→读取题卡→回复文字→首段声音”的时间。识别模型推理与平台回复耗时分开统计；本次不调整模型精度或推理参数。


性能优化后，Java入口另跑4组桌面／移动端线程预算检查，JS增加“引擎准备完成前不创建练习”与耗时字段保存检查。真正的性能数字必须使用固定Q5权重和实际原生库测量，不能用替身的毫秒数字代替。

`AsrBench.java` 参数依次为模型、短WAV、较长WAV、线程数、结果JSON，连续运行冷态和热态三次；使用前确认测试输出在临时目录。Windows候选的完整保存／识别RPC及CPU回退已在隔离目录复验，步骤和局限见docs/Windows识别性能_20261102.md。

Windows随附模型修复增加6组隔离夹具检查：首次直接使用随附文件、公开实际路径、错误导入保留已验证模型与随附源、重启保留历史、拒绝删除随附模型、损坏／缺失随附模型不误报就绪。完整模型与真实小智联调另外运行，不能用夹具代替性能或准确率验收。

开始练习保存修复：Java另有3组真实临时文件写入／读取／写入失败保留原记录与明确错误码检查；JS增加首次保存失败后再次开始可成功、未保存不得联系考官的检查。Windows支持程序根目录私有.qihang-data.json的directory指定数据位置（可为相对路径），用于受限环境；此文件及记录不随分享包分发。提醒进程使用同一位置。迁移时先一致备份、逐文件核对，不删旧记录。

引导问答顺序检查：新一轮的前两题为姓名和年龄，随后四个不同主题随机变化；覆盖陪练/模拟、单独/整套，实际姓名→年龄→后续题卡、请求重复不推进、首句主动提供年龄时跳过（不误用兄弟姐妹的年龄）、旧计划/旧成绩保留与题库44题计数。可设置QIHANG_TASK_EVIDENCE输出合成考生文本的前三轮客户端题卡供平台联调，勿指向正式数据。

引导问答计时检查（共14组JS检查）：使用虚拟时钟分别在考官问题返回、录音、识别和最终回复等待期间越过90秒；保持本轮计划可继续作答，全部计划回答后等考官收尾才完成，不取消录音／识别／清空音频。收尾失败可以继续重试；实际renderProgress函数在00:00显示继续问答提示，收到完成状态才显示✓。这些均为隔离替身和虚拟时间，不表示重新验收真人麦克风、ASR或平台性能。
