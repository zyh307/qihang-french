# 法语口语助手模块介绍

可以复制以下文字发到项目组：

我这边完成了启航法语的DELF A1语音口语助手，源码已提交合并请求。它支持引导问答、信息交换和情景对话三个环节：42个问句随机组合，48张词卡每轮抽6张，12个生活场景可随机或自选。流程是“录音→本机独立法语识别→小智考官→法语语音回复”，结束后会根据实际发言给出中文点评、表达改写和练习建议，也能回听原声、查看历史和导出记录。

目前是可单独运行的浏览器模块，还需要安装Python依赖、下载法语模型，并绑定自己的小智智能体；尚未整合进主应用或APK。题库、参考答案和示范对话文档也已附上，参考答案只在文档里。个人录音、学习记录和密钥均未上传。欢迎大家先按模块README运行，再一起讨论界面整合、更多级别题库和服务器部署。

代码位置：`oral-assistant/`。AI点评目前依据文字，暂不评发音，也不作为官方考试成绩。
