2. 连字符差异会被判错。
3. “已会”容易误触且没有二次确认；从已会本移出不便，希望在选词界面长按弹出扇形词本选择。
4. 首页“开始复习”下增加“学习调整”，新学和复习分别滑动设置每组3—15词；数值、滑钮、轨道填充同步。
5. 同一词错误达到三次后，当天不再重复出现，随后三天安排复习，不能卡住其他词。

## 实施顺序与方案

### 1. 判分与无意义对比（先修规则）

入口：`src/domain/learning.js`的normalize/checkAnswer、`spelling-diff.js`、`word-display.js`冠词拆分、`conjugation/sessions.js`与匹配引擎check。

- 统一普通词和变位的比较规则。容忍空格数量/首尾/不换行空格及常见连字符的格式差异，避免“格式差异”触发错误或弹出空白对比页。
- 空格与连字符的宽容不能吞掉实际字母、冠词阴阳性或人称错误；重音、oe/œ沿用既有模糊识别开关。
- 真正需要展示重音/连字差异时保留字母标黄，纯空格/连字符差异不展示无意义对比。

### 2. “已会”防误触和词本快速调整

入口：`DefinitionPanel.vue`、`ConjugationDetails.vue`、`pages/index/index.vue`的markKnown/markPreviewKnown、确认弹窗与moveWord、`RecitationPanel.vue`及词本/选词条目。

- 统一确认：已会按钮与调整词本→已会都须确认后才修改数据；取消不改题目/进度。原型与每个变位时态分开确认。
- 最新指示覆盖原方案：已会按钮保留原底部位置，普通点击须二次确认；按下处出现圆形扩散波纹。
- 不使用扇形菜单或弹窗。词条长按480ms后抬起卡片，向上拖至少70px，进入上方目标区域后松手才提交；拖不够、移出目标、滑回、系统取消均不修改。长按前移动超过9px按正常滚动处理，松手拦截残留点击。
- 未会词上拖加入已会；已会词同样上拖放回复习，目标位置不变，仅文字/图标切换。该明确拖动手势不再额外弹确认框。浮起、吸附与取消回位均不增加布局占位，遵循减少动态效果偏好。
- 仍保留原词本调整入口用于其他归属选择，电脑可使用鼠标长按拖动或原按钮。

### 3. 每组数量独立设置

入口：`HomeDashboard.vue`、`AppSettings.vue`、`learning.js`的roundSize/openRound/startSession、`conjugation/match-engine.js`分组及会话创建、备份验证与简短教程。

- 设置分别保存learnGroupSize/reviewGroupSize，范围3—15，兼容现有groupSize；旧记录默认新学5/复习10。
- 首页复习入口下提供“学习调整”，两块独立滑杆。使用一个实时数值源驱动轨道填充、滑钮位置和上方数值；拖动不另加滞后动画，松手吸附采用同一时长/曲线。
- 修改只影响下一组，不扩大/缩小当前未完成组，不重抽已冻结题目/选项。
- 保持普通学习、复习、导入本和变位入口单位清晰；一个变位时态仍算一个词条，不把六个人称误算成六个设置单位。

### 4. 三次错误后当日暂停与连续三日复习

入口：`learning.js`的recordMistake/revealHint/submitAnswer/advance/refresh、`review-plan.js`、复习队列、提醒计数、`conjugation/sessions.js`和`match-engine.js`。

- 按“达到第3次错误”实施。单日错误尝试计数与原有“同词每轮只计一次”的错题累计分开，不直接复用history.count。
- 当天该词（变位以时态为单位）累计第三次错后，移除当前及后续当天队列中的待答/巩固任务，保留其他词与组内进度。暂停不算答对、不记完成、不标已会。
- 新建独立的连续三日复习日期列表，保留原正常due/学习日锚点；与正常到期、次日加练同日时去重。
- 重新进入学习/复习/错题/收藏/专练也不能把当天暂停词重新塞回队列。切后台、重启和跨日都持久保持。
- 只消费实际完成的额外任务；未做任务顺延，不伪造完成。既有“普通复习答错才追加一次次日加练”规则不被覆盖。
