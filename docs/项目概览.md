# 启航法语项目概览

启航法语提供词汇、语法、DELF 模拟及桌面日常口语练习。桌面口语以 Inspire 1 的单元主题为依据，内置原创练习文本、中文提示和离线合成示范。用户可按课复练，或在口语小镇完成短回合。

## 随软件提供的口语内容

| 模块 | 覆盖范围 | 一次怎么练 |
| --- | --- | --- |
| 读课文 | 8 个单元，8 篇主题短文，32 句 | 逐句盲读、查看识别反馈、听示范，然后跟读。进度与待练句按课保存。 |
| 接拍串说 | 8 个单元，每课 6 条，共 48 条节奏链 | 先按意群热身，再整条连说。每次反馈一个节奏问题。 |
| 看提示换一格 | U5 日常与运动，3 个句框，12 张提示卡 | 看提示选择 `du sport` 或 `de la muscu`，连续口答。沿用此前通过真人盲测的词形对。 |

日常练习卡展示六维训练侧重。「今日练习」汇总开口与完成记录，「需练习本」保留各模式的复练条目。游戏地图提供三种短练习入口，配有商店、种植和本机电台。

## 从安装到第一轮

1. 使用电脑，在仓库根目录执行 `npm ci` 和 `node scripts/build-lecture.mjs`。
2. 按 [本机口语安装说明](../oral-assistant/README.md#安装与启动) 安装 Python 3.12 环境与法语识别模型。首次获取依赖和模型需要联网。
3. 在 Windows 双击 `oral-assistant/启动日常口语.cmd`。已经启动本机服务时，可以从主软件的「口语 → 打开电脑日常口语」打开。应用内可从「日常练习 → 项目概览」返回内容介绍。
4. 先进入「正常开始」，任选一课听示范并完成一轮。启用本机模型后，三个日常练习可以断网完成。可在原页面刷新续练。

随包文本和法语示范存于 `oral-assistant/content/starter-speaking/`。用户可以另外安装授权的教材原声；已有会话和课包编号保留。游戏音乐、模型参数与学习记录由本机管理。电脑日常口语通过独立本机服务运行，现有原生 DELF 考试入口可继续使用。

## 示范音来源

项目使用 Piper 1.8.0 的法语 `fr_FR-siwis-medium` 模型生成练习示范。SIWIS 语料由爱丁堡大学发布，模型卡标明 CC BY 4.0。随仓库提供的是原创文本合成所得的 16 kHz 单声道 WAV。可用 `oral-assistant/scripts/build_starter_speaking.py` 重建。[Piper 模型卡与语料署名](https://huggingface.co/rhasspy/piper-voices/blob/main/fr/fr_FR/siwis/medium/MODEL_CARD) · [SIWIS 数据集](https://datashare.ed.ac.uk/handle/10283/2353)

生成使用的模型 SHA-256 为 `b1d946fd68d0347155fa59bce0a018924abbef3c1561181db45ca463d83963ef`。Windows 环境若 Piper 无法定位自带的发音数据，可将 eSpeak NG 1.52 解压到纯英文路径，并通过生成脚本的 `--espeak` 参数给出可执行文件。

## 交付验证

- 使用干净检出和独立练习目录完成 npm 安装、桌面口语及 H5 构建。真实 H5 首页经模式菜单、口语入口打开本机练习服务和项目概览。
- 执行 130 项 Python 单测。Edge 新会话使用模拟麦克风和实际本机 Whisper，检查朗读、接拍串说、换一格、刷新续练、历史报告、今日练习、需练习本、建角及无默认电台素材时的界面。测试阻断外部网络。代表性完整轮结果为朗读 4/4、节奏链 5/6（1 条识别证据不足）、词形提示 12/12；另用 4 张故意选反的词形卡验证全部要求重来。
- 浏览器回归脚本在 `oral-assistant/tests/smoke_starter_speaking.mjs`。需要复验时只对隔离服务运行，设置 `QIHANG_TEST_ORIGIN`、`QIHANG_E2E_DATA=isolated`，并安装 `playwright-core` 或用 `QIHANG_PLAYWRIGHT` 指定本机 Playwright 模块目录。实体麦克风、原生 Windows 安装包与独立人工验收另行验证。
