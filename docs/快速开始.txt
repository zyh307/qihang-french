启航法语 v__VERSION__

打开软件
Windows：完整解压 Windows ZIP，双击“启航法语.exe”，保留配套文件和文件夹。
安卓：安装 APK；更新时覆盖安装，不要先卸载。

同一电脑从 2.4 升级（首次做一次）
1. 用原浏览器打开 2.4：设置 → 词汇 → 资料 → 词汇备份（含录音），保存 ZIP。
2. 关闭旧版网页，打开新版 EXE，把 ZIP 拖进窗口，点确认。备份 ZIP 不用解压。
3. 核对进度后再清理旧程序，保留备份。若提示旧版仍在运行，等 3–4 分钟再打开。
以后更新 EXE 会自动读取原记录，无需重复迁移。

换电脑或手机
旧设备：设置 → 通用 → 全部记录备份，保存 ZIP。
新电脑：把 ZIP 拖进软件，确认恢复。新手机：设置 → 通用 → 恢复记录，选择同一 ZIP。
备份含词条、课次、词本、学习进度、语法和口语记录；只有口语录音随备份，不含词汇音频。
电脑版记录固定保存在 %LOCALAPPDATA%\QihangFrench；清理外部浏览器的 Cookie 不影响这里的记录。

口语首次使用
1. 单独准备 ggml-model-q5_0.bin（约 1.08 GB），设置 → 口语 → 导入本地模型，等待校验。
2. 允许麦克风，绑定自己的小智账号和智能体；使用软件内的考官配置。
3. 等待模型和考官就绪后练习。电脑和手机分别绑定。
词汇和语法无需导入模型。备份不含识别模型和小智绑定，新设备需单独配置。
