# 日常训练游戏模式

M1 提供入口、角色创建、三区行走和黑洞交互。M2 接入真练习、金币与名称解锁。M3 接入商店、四格农田、收获和等级。M4 接入首次开场、家园换装和素材设置。

## 技术五问

1. **Canvas**。Canvas 2D 画 16×16 像素瓦片、16×24 角色（4 帧 × 4 朝向）、影子、黑洞及粒子。家和商店各 20×12 格，逻辑画布 320×192，2× 后为 640×384。野外 24×14 格，384×224，2× 后为 768×448。按容器宽度选择 1× 至 3× 整数倍。最近邻放大。地图底图按区缓存，动态层每帧绘制。
2. **Vue**。气泡、角色创建、店铺、农田格、HUD、换装和设置用普通 DOM。整区入屏，无相机。若逻辑点为 `(x,y)`，Canvas 的显示边界为 `r`，屏幕点是 `(r.left + x * r.width / canvas.width, r.top + y * r.height / canvas.height)`。实现用共用容器内的百分比定位，气泡固定在黑洞上方。
3. **移动**。WASD 或方向键，3.8 格/秒并归一化斜向。脚点四角检测瓦片障碍，按轴处理滑动。道路外可走，建筑、床、田块、货架、水池和树丛有碰撞。最大边长估算 24 ÷ 3.8 ≈ 6.3 秒，野外对角直走约 7.3 秒。障碍绕行以可达格测量。
4. **切区**。家园中路往上通过北门去野外，往下通过南门去商店。家北门 ↔ 野外西边，家南门 ↔ 商店北门，野外东边 ↔ 商店南门。过门时落到对侧门内，位置随走路与切区存档。地图、碰撞和标签在同一更新中切换。
5. **存档**。`localStorage['qihang-daily-game']`，M4 使用 `version: 4`。v1 先补齐冒险字段，v2 再追加背包、四格农田和累计经验，v3 追加开场状态和素材选择。既有角色、位置、金币、黑洞名称、领取日期和待续会话都保留。未知版本保留原数据。位置、练习结算、购买、种植和外观通过同一存储锁更新。练习结果由现有本机模块保存。

## 练习接口

```ts
type Mode = 'lecture' | 'fluency' | 'slot'
type NodeId = 'rift-west' | 'rift-center' | 'rift-east'

interface PracticeRequest {
  origin: 'game'
  nodeId: NodeId
  mode: Mode
  runId: string
}

interface PracticeResult {
  mode: Mode
  itemCount: number
  pass: number
  retry: number
  accuracy: number | null
  durationMs: number
}
```

- 西、中、东依次为读课文、接拍串说、看提示换一格。读课文优先选已安装的 Inspire 1 第 16 课 Piste 78，缺包时选精选或首个可播放课次，取前 3 句。串说取当前试点课包前 3 条链，换一格取第 1 组 4 张卡，保留原有试听流程。
- `practiceBridge.js` 生成入口和会话编号，`game_practice.py` 验证模式与黑洞映射。重复启动返回同一个冒险会话，刷新或从原黑洞恢复。普通最近一轮、朗读报告与需练习本独立。点击「结算并返回地图」时验证该会话已完成，然后回到出发位置。首次有效通关解锁名称。
- `pass` 计无辅助通过的不同条目，`retry` 计明确触发重试的不同条目，两者可以重合。分母 `itemCount` 为句子、链或普通提示卡的总数。 `accuracy` 是独立通过比例，证据不足时为 `null`。接拍和换一格的 `durationMs` 为原会话活动时间，朗读暂用实际上传录音时长之和。
- 将来三个模块都原生接收请求并发出统一结果事件后，移除适配层的入口转译和结果汇总代码，保留黑洞映射与结算。

## 经济与成长

| 项目 | 数值 | 规则 |
| --- | --- | --- |
| 一次练习金币 | 基础 +12，最多 +21 | 独立通过不同条目每项 +2，最多 3 项；通过率 ≥80% 加 3 |
| 种子 | 30 金币 / 3 粒 | 三个黑洞各完成一次即可购买 |
| 水 | 2 金币 / 份 | 每格浇一次；三轮最低 42 金币，种子加三份水需 36 |
| 生长 | 浇水后 30 分钟 | 保存 `plantedAt`、`wateredAt`、`readyAt`。按当前时间显示阶段，关掉也推进 |
| 收获经验 | +12 XP / 格 | 同一格的同一株只能收获一次 |
| 首次升级 | 24 XP | 收获两格即到 Lv.2。后续每级所需经验增加 12 |

有效完成至少包含一个有充分识别证据的独立通过。同一黑洞、同一角色每天首次有效完成发一次奖励，同一天继续复练可练习但不重复领金币。重复回传按会话 ID 去重，条目奖励按稳定条目 ID 去重。第一小时建议平行种三格，前三轮能买一包种子与三份水，30 分钟后收两格即可升级。

在商店靠近柜台按空格或回车打开商店，在家园靠近田边按同样的键打开农田。面板显示背包库存、余额与差价。田格可由空地播种、由已播种浇水、在成熟后收获。浇水前的等待不计入生长时间。成熟从保存的 `readyAt` 推导，刷新、关闭浏览器或离开地图期间都按本机时钟计时。收获后清空该格，可再次种植。

家园靠近床边按空格或回车打开换装，五层各两种选择，提供实时预览，保存后地图上的角色立即更新。按 Esc 或「返回地图」撤销尚未保存的选择。地图上方的「画面设置」可持久选择本机素材或内置图形。

## 试玩入口

- 游戏地图右上角打开电台，点「开始收听」后播放。`M` 切换静音。可选默认曲库放在 `assets-private/radio/`，自选 MP3、M4A、OGG 或 WAV 保存在当前浏览器。进练习会停播，回地图默认从原位置恢复。重开游戏后需要再点一次收听。
- `src/game/GameMode.vue`、`world.js`、`graphics.js` 实现角色、地图、键盘、房门和气泡。`save.js` 持久化角色和进度，`practiceBridge.js` 负责真练习与结算。
- `src/game/TownPanel.vue` 显示商店和农田，`farm.js` 负责价格、田格状态、成熟时间和等级计算。
- `src/game/OpeningStory.vue` 播放开场，`AppearanceEditor.vue` 为创建角色与换装共用五层选项和预览。
- `src/oral/desktop/GuidedOral.vue` 增加正常开始和游戏模式入口。
- 素材在 [ASSETS.md](../ASSETS.md) 登记。私有路由只在本机预览启用。`scripts/private-assets.mjs` 在构建中拦截私有目录的导入，在 APK/ZIP 收集文件时排除目录。
- 本机试玩从项目根目录 `node scripts/build-oral.mjs` 构建，用 `oral-assistant/启动日常口语第2步.cmd --game-private-assets` 启动，进入日常练习的「游戏模式」。加 URL 参数 `assetSource=cc0` 即可检查无图回退。
- 可用 `git check-ignore -v assets-private/radio/001-test.wav` 检查本机媒体的 Git 排除规则。APK 和 ZIP 共用 `scripts/private-assets.mjs` 的目录判断，验证实际包体时可检查归档条目。
