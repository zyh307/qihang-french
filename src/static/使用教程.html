启航法语：打开与资料导入教程

Inspire 1–4 与 FOS 1 已内置，打开应用即可选择教材和 Lesson。下方导入步骤用于更新资料或添加自己的课次。

1. 一键打开2. 准备总表与录音3. 录音如何对应4. 在软件中导入一课5. 学习与复习6. 更新资料与备份7. 发给别人使用8. 常见问题9. 安卓安装和更新10. 口语模式11. 导入单词12. 学习记录与分享

1. 一键打开

  1. 完整解压“启航法语”的 Windows ZIP。
  2. 打开“启航法语”文件夹，双击“启航法语.exe”。
  3. 下次仍从同一启动文件打开，学习记录会自动恢复。

Windows 10／11 完整解压后打开“启航法语.exe”。Android 8 及以上可安装下载页中的 APK。安卓安装后打开应用即可选择 Lesson。

2. 准备总表与录音

准备 Inspire 1 词表时，使用“词库总表.xlsx”，保留“词库总表”工作表名称和以下十列表头。每行一个主词条，不合并单元格，不使用公式。

列名填写方式
课次L01、L02 等，必须与导入窗口的课次编号一致。
序号001、002 等；同课唯一，下一课重新从 001 开始。
法语法语词条；名词连冠词填写，阴阳性同格用 / 隔开。
音标可选，按原资料填写。
词性n.m.、n.f.、n.、adj.、v.、prép.、loc.、num. 等。
中文中文释义，多个意思用中文分号隔开。
例句对应的法语例句；一行只需一个。
音频对应文件名，例如 L01_001.mp3。
真人音频有真人录音时填写文件名；留空时按“音频”列查找。
状态资料校对状态，例如“已校对”，不代表已经学会。

多课可以保存在同一张总表中。排序时移动整行，不要拆开编号和词条。新增词使用新序号，已用序号不要改给其他词。

冠词与词形

名词可以填写 le livre、un ami、du pain、de la confiture、de l’eau。填空默认点击填写框左侧的冠词栏，在下方选择 un 或 une，再填写单词；其他形式按题目给出的冠词填写。在设置选择“自行填写”后，名词连冠词填写，接受性别正确的冠词。

阴阳性共用一行，例如 un ami / une amie、un acteur / une actrice；阳性在前、阴性在后，共用本行例句。录音按词形分别播放。

保留原资料中的词性；n.m.pl.、n.f.pl.、v.i.、v.t.、v.pr. 也可识别。介词等直接填写词条和相应词性。

配套录音 ZIP 内含例句中文翻译。也可以在总表末尾添加可选列“例句翻译”和“例句音频”；句音文件名如 L01_001-example.mp3。可填写课本出处。

3. 录音如何对应

使用真实 MP3，文件名按“课次_序号.mp3”命名，例如 L01_001.mp3、L01_002.mp3、L02_001.mp3。001 是课内序号，不是 Excel 行号。

一行有两种性别时，分别提供 L01_001-m.mp3 和 L01_001-f.mp3；第三种形式使用 -base.mp3。表格“音频”列仍填写 L01_001.mp3，软件优先读取分词形文件。只有共用录音时可使用原文件名。

使用配套的“词形录音.zip”。自行准备时按上述文件名打成 ZIP，允许包含课次文件夹。总表和录音 ZIP 建议放在同一个位置，便于同时选中。

词库总表.xlsx
词形录音.zip
└─ 词汇真人/
   ├─ L01_001.mp3
   ├─ L01_002.mp3
   ├─ L02_001.mp3
   └─ ……其他录音

只导入总表也能学习；同时导入配套录音 ZIP 可载入单词录音、例句翻译和例句音频。缺录音的词会显示暂无录音。补录音时保留原序号，按更高内容版本重新导入。

4. 在软件中导入一课

  1. 点击右上角“导入课次 / Importer”。
  2. 第一课填写：课次编号 L01，课次名称 Leçon 1，排序 1，内容版本 1。
  3. 点击“选择文件并预览”。电脑按住 Ctrl，同时选中“词库总表.xlsx”和“词形录音.zip”；安卓在系统文件选择器中长按文件，选中这两个文件，再点击打开。只有词表时可以只选 XLSX。
  4. 查看预览中的词条、形式和录音数；软件只读取总表里 L01 的行。
  5. 检查缺少资料提示，需要核对文件名时可下载录音命名清单。
  6. 点击“确认导入”，然后试听本课录音。

导入 L02 时，把课次编号改为 L02，名称和排序相应修改，再选择同一份总表与录音 ZIP。其他课次依次操作，各课独立学习。

仅把资料复制到程序目录不会自动导入，仍须在软件中选择文件并确认。

5. 学习与复习

在首页选择教材和 Lesson，点击“开始学习”。卡片正面显示法语，点击查看中文，再点“释义”查看例句。点击“进入练习”开始答题。课次选择页的“预览”可查看本课词汇。

单词练习先选中文，再填写法语。填空页左下角“释义”可查看单词；答错后点“重试”重新填写。冠词可从列表中选择，也可在设置中改为自行填写。重音字母在手机键盘上长按选择，电脑可使用填空页的重音按钮。

变位练习每轮三个不同动词原型，先混合配对，再填空。点左下角“释义”查看当前动词和时态，返回后继续答题。一组完成后点“继续练习”进入下一组。

在首页点击“开始复习”。词本中的“复习”“收藏”“错题”和“已会”可分别查看对应词汇。点击词条查看详细释义；长按词条并向上拖动可调整词本。“已会”按钮也需要向上滑入目标区后松手。

首页“学习调整”可以分别调整新学和复习的每组词数。设置中可选择配色、卡片切换效果、冠词输入方式和提醒时间。

6. 更新资料与备份

更新课次时保留原课次编号，导入新的总表和完整录音 ZIP。确认前请核对预览内容；更新会替换该课的词汇资料。

设置 → 通用 → 全部记录备份，可保存学习记录。恢复时选择同一 ZIP 并确认；电脑也可直接把 ZIP 拖进软件。恢复会替换当前设备的记录，建议先保存一份备份。

同一电脑更新后直接打开新版 EXE。手机更新时覆盖安装，不要先卸载。

从旧版 2.4 首次升级到 EXE：先在旧版设置中导出词汇备份，关闭旧版，再将 ZIP 拖进新版窗口恢复。备份文件不用解压。

7. 发给别人使用

电脑：发送完整 Windows ZIP，对方解压后双击“启航法语.exe”。请保留配套文件和文件夹。

安卓：发送 APK，安装后打开“启航法语”。

8. 常见问题

总表中没有指定课次

检查“课次”列是否与导入窗口一致，例如都为 L01。

没有录音

检查音频文件名与表格中的编号是否对应，并确认录音包含在所选 ZIP 中。

编号错误或重复

同课每行使用不同的三位编号，例如 001、002。检查是否漏填或重复。

录音无法播放

确认文件为可播放的 MP3；重新导入损坏的音频文件。

程序打不开

电脑请完整解压安装包后再打开“启航法语.exe”。安卓请安装适用于 Android 8 及以上的 APK。

9. 安卓安装和更新

安装 APK，按系统提示允许安装。更新时直接覆盖安装，卸载前请先导出学习记录。

需要复习提醒时，在设置中允许通知并选择提醒时间。口语录音需要麦克风权限。

10. 口语模式

首次使用：

  1. 单独准备 ggml-model-q5_0.bin，在设置 → 口语 → 导入本地模型中选择文件，等待校验完成。
  2. 允许麦克风访问，点击“绑定小智”。
  3. 打开小智控制台，登录自己的账号，新建“DELF 法语口语考官”智能体，选择账号可用的模型和法语音色。
  4. 点击软件中的“复制考官配置”，粘贴到智能体的角色配置并保存。
  5. 在小智控制台为该智能体添加设备，输入软件显示的绑定码。
  6. 返回软件，等待显示“已连接”，进入口语练习。电脑和手机分别绑定。

练习时点击“开始说话”，说完点击“我说完了”。识别后考官会接话；“结束并保存”可查看中文点评、表达改写和练习建议。历史记录可回听和导出。点评依据识别文字，不评价发音。

词汇和语法无需导入口语模型。使用小智考官需要联网；本地识别模型和绑定需在每台设备单独配置。

11. 导入单词

选择导入本，点击“导入单词”，用逗号分隔输入法语词汇。可选择已有 Lesson、自动分课，或点击 ➕ 新增 Lesson；课次“预览”旁的 ➕ 可直接向该课加词。

完全匹配的词可直接导入；有多个候选时选择所需词条。有变位的动词可选择原形或展开时态列表。导入完成后，下方会显示成功导入的词和所在 Lesson。

在导入本中点击“开始学习”打开背诵卡片，再进入练习。词条的移除图标可移出导入本；详细释义中的“主释义”可切换背诵时使用的意思。

12. 学习记录与分享

记录页可切换月份、选择日期，查看当天学习的词。点击单词可打开释义。

设置 → 通用 → 分享学习记录，可选择名言、背景和当天完成的 Lesson，保存或分享图片。
