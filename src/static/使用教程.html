启航法语：打开与资料导入教程

Inspire 1 的 23 个 Lesson、549 个词条、612 段单词录音和 549 段例句音频已内置，打开应用即可开始学习，无需再次导入。下方导入步骤用于后续更新或添加自己的课次。

1. 一键打开2. 准备总表与录音3. 录音如何对应4. 在软件中导入一课5. 学习与复习6. 更新资料与备份7. 发给别人使用8. 常见问题9. 安卓安装和更新错题复习10. 口语模式动词变位逗号导入单词复习日历与提醒口语首次配置

1. 一键打开

  1. 完整解压“启航法语”的 Windows ZIP。
  2. 打开“启航法语”文件夹，双击“启动启航法语.bat”。
  3. 等待浏览器打开；未自动打开时输入 http://127.0.0.1:5188/ 。
  4. 下次使用同一浏览器和启动文件打开。

Windows 10／11 无需安装 Python 或 Node.js。首次使用自动载入 Inspire 1–4 词库。Android 8 及以上可安装下载页中的 APK。安卓安装后打开应用即可选择 Lesson。

2. 准备总表与录音

Inspire 1 资料整理在项目“词库/Inspire1”目录。使用“词库总表.xlsx”，保留“词库总表”工作表名称和以下十列表头。每行一个主词条，不合并单元格，不使用公式。

列名填写方式
课次L01、L02 等，必须与导入窗口的课次编号一致。
序号001、002 等；同课唯一，下一课重新从 001 开始。
法语法语词条；名词连冠词填写，阴阳性同格用 / 隔开。
音标可选，按原资料填写。
词性n.m.、n.f.、n.、adj.、v.、prép.、loc.、num. 等。
中文中文释义，多个意思用中文分号隔开。
例句对应的法语例句；一行只需一个。
音频对应文件名，例如 L01_001.mp3。
真人音频有真人录音时填写文件名；留空时按“音频”列查找。
状态资料校对状态，例如“已校对”，不代表已经学会。

多课可以保存在同一张总表中。排序时移动整行，不要拆开编号和词条。新增词使用新序号，已用序号不要改给其他词。

冠词与词形

名词可以填写 le livre、un ami、du pain、de la confiture、de l’eau。填空默认点击填写框左侧的冠词栏，在下方选择 un 或 une，再填写单词；其他形式按题目给出的冠词填写。在设置选择“自行填写”后，名词连冠词填写，接受性别正确的冠词。

阴阳性共用一行，例如 un ami / une amie、un acteur / une actrice；阳性在前、阴性在后，共用本行例句。规则阴性加 e 默认只考阳性，其他形式分别练习。录音按词形分别播放。

保留原资料中的词性；n.m.pl.、n.f.pl.、v.i.、v.t.、v.pr. 也可识别。介词等直接填写词条和相应词性。

配套录音 ZIP 内含例句中文翻译。也可以在总表末尾添加可选列“例句翻译”和“例句音频”；句音文件名如 L01_001-example.mp3。已有出处照常显示。

3. 录音如何对应

使用真实 MP3，文件名按“课次_序号.mp3”命名，例如 L01_001.mp3、L01_002.mp3、L02_001.mp3。001 是课内序号，不是 Excel 行号。

一行有两种性别时，分别提供 L01_001-m.mp3 和 L01_001-f.mp3；第三种形式使用 -base.mp3。表格“音频”列仍填写 L01_001.mp3，软件优先读取分词形文件。只有共用录音时可使用原文件名。

使用配套的“词形录音.zip”。自行准备时按上述文件名打成 ZIP，允许包含课次文件夹。总表和录音 ZIP 建议放在同一个位置，便于同时选中。

词库总表.xlsx
词形录音.zip
└─ 词汇真人/
   ├─ L01_001.mp3
   ├─ L01_002.mp3
   ├─ L02_001.mp3
   └─ ……其他录音

只导入总表也能学习；同时导入配套录音 ZIP 可载入单词录音、例句翻译和例句音频。缺录音的词会显示暂无录音。补录音时保留原序号，按更高内容版本重新导入。

4. 在软件中导入一课

  1. 点击右上角“导入课次 / Importer”。
  2. 第一课填写：课次编号 L01，课次名称 Leçon 1，排序 1，内容版本 1。
  3. 点击“选择文件并预览”。电脑按住 Ctrl，同时选中“词库总表.xlsx”和“词形录音.zip”；安卓在系统文件选择器中长按文件，选中这两个文件，再点击打开。只有词表时可以只选 XLSX。
  4. 查看预览中的词条、形式和录音数；软件只读取总表里 L01 的行。
  5. 检查缺少资料提示，需要核对文件名时可下载录音命名清单。
  6. 点击“确认导入”，然后试听本课录音。

导入 L02 时，把课次编号改为 L02，名称和排序相应修改，再选择同一份总表与录音 ZIP。其他课次依次操作，各课独立学习。

仅把资料复制到程序目录不会自动导入，仍须在软件中选择文件并确认。

5. 学习与复习

首页分别选择教材和 Lesson。选好教材后返回首页，Lesson 可稍后选择；未选 Lesson 时点开始会提示“请选择 Lesson”。首页提供“开始背诵”“直接练习”和“继续上回进度”，可直接回到最后一次练习。到期复习从首页开始，分享位于设置页。

“开始背诵”打开法语卡片。每排 3 张卡片，点击后原位翻面，显示词性和中文，每张卡各自 3 秒后翻回，可同时翻开多张卡片；“释义”小箭头打开详细释义，发音按钮播放单词。背诵页下方可进入练习。直接练习会接着本课未完成的练习继续，没有进度时从新的一轮开始。

Lesson 选择页可点“预览”查看只有法语的词汇列表，预览不改变已选 Lesson。Lesson 每排 3 个，重点 Lesson 单独置顶；已学词排在下方并变灰。全部完成后可一键放回练习本，确认后重新开始本课练习。记录页点击单词直接查看对应释义。

每轮 5 个单词，先选择中文再填空。组内顺序固定；设置中的“课内乱序学习”默认关闭，开启后在开始本课时打乱词序。整课完成后可进入下一课。四个选项位于下方，按两行两列排列；选错标红，可以继续选，选对后进入释义。选择题自动播放例句，无例句时播放单词；释义自动播放单词。法语例句柔和高亮对应词汇，释义下方有中文译文，并可单独播放例句。

填空错后可直接重填，输入框清空、对比提示消失，不切换卡片。正误对比显示在填空题下方；重音不准确但模糊识别判对时，对应字母标黄。答错或查看提示后仍须独立答对，并在之后巩固一次。

冠词选项竖排，跟随词表：le、la、l’、les；un、une、des；部分冠词；交通表达选择 à 或 en。只对明确冠词设选项，au bout 等固定搭配整体填写。设置可切换为自行填写，按性别判断冠词。按键、正确答案和“已会”成就有轻提示音，可在设置关闭。键盘弹出时保持页面和词本搜索布局。手机填空使用内置 QWERTY 法语键盘，无候选词、联想或自动补全。长按 e 在原键上方弹出 é、è、ê、ë 等字母，滑动高亮、松手输入，a、c、i、o、u、y 同样支持重音或特殊字母。OK 或实体键盘回车提交；箭头收起键盘。键盘浮在页面下方，不改变题目布局。填空答对后播放单词录音。

复习将所有课次的到期单词混合打乱，每轮 5 词，进度按原词条保存。答对后停留在题目，可直接下一题或查看释义；结束页列出本次新加入已会本的词。复习本显示已学习天数和剩余复习天数，首日为第 1 天。词本内可直接收藏单词；导入词旁的移除图标只移出导入本。Lesson 旁的星标收藏整课，单词收藏保留在释义卡片原位置。已会词停止自动复习，仍可手动练习。不同 Lesson、学习与复习、单词专练分别保存进度。

答错或填空查看提示都会进入错题本，同词每轮最多计错一次。错题按累计错误次数排列，当天完成后放在下方，当天不再练习。完整复习两次后可移出，也可关闭“复习两次后移出”保留词条；错误次数和复习次数仍会保存。错题练习不改变普通复习进度。专练完成的未学词进入复习本。

应用内复习弹窗每天最多一次。仅到期复习发送系统通知，每天最多一次，时间可在设置修改；错题每两天仅在软件内提示。两类提醒及“复习答错，次日加练”分别开关，默认开启。待练词达到 10 个显示红点，点击对应练习入口消除。学习日历可查看每日记录。

分享卡展示今日新词和名言。自选背景可调左右、上下位置和缩放。

6. 更新资料与备份

同一课更新时，课次编号不变，内容版本递增，例如 1 改为 2。选更新后的总表和完整录音 ZIP；本课原有内容会被替换，能够对应的词形进度保留，其他课次独立保存。

设置中的“词汇备份（含录音）”用于转移自己的词库、词汇录音、设置与学习记录。“恢复词汇备份”会替换当前本机的词汇学习资料，不改动口语历史。

学习记录保存在当前设备、当前浏览器中。换浏览器、清除网站数据或换电脑前，请先导出备份。

7. 发给别人使用

发送 Windows ZIP，对方完整解压后双击“启动启航法语.bat”，无需安装 Python 或 Node.js。请保留“网页”和“口语运行”文件夹。程序分享包不携带你的学习历史或小智身份。

分享课程时另发“词库总表.xlsx”和“词形录音.zip”，让对方按第 4 节导入。完整学习备份包含个人进度，只用于需要转移记录的情况。

更新程序时覆盖原分享版文件，再刷新原浏览器页面；继续使用同一浏览器和地址可读取已有记录。

8. 常见问题

总表中没有指定课次

检查“课次”列与导入窗口是否完全一致，例如都为 L01。提示中会列出总表已有的课次。

没有录音

检查是否同时选择了录音 ZIP，文件名是否与“真人音频”或“音频”列一致，例如 L01_001.mp3。预览会列出缺少的文件名。

编号错误或重复

序号填写 001、002 等正整数，同一课不能重复；不同课可以重新编号。

录音无法解码

确认是真实 MP3，能在播放器中播放。修改文件扩展名不会完成格式转换。

提示需要更高版本

同一课再次导入时，增加导入窗口中的内容版本，不更改课次编号。

程序打不开

确认完整解压，保留“网页”和“口语运行”文件夹，再双击启动文件。启动后刷新浏览器；如果程序已经打开，请返回原窗口。

9. 安卓安装和更新

将下载页的安卓 APK 发送到手机，点击安装。支持 Android 8 及以上的 ARM64 设备。更新采用原应用身份，保留记录、模型和绑定。手机可能要求允许当前文件管理器安装应用，按系统提示操作。词汇学习可离线使用；口语对话需要联网。

正式 Inspire 1 内容已打包进 APK，安装后可直接学习。需要更新某课时，再把总表和录音 ZIP 传到手机，按第 4 节操作。

安卓保存备份或图片时会出现系统保存窗口，选择位置后确认；“分享”打开系统分享面板。学习数据保存在应用内部。卸载前请先导出词汇备份和需要保留的口语练习记录。

设置中打开“复习提醒”并允许通知。有到期复习时每天安排一次，未完成的词会继续保留；勿在系统中强行停止应用。后续安装同签名的新版本可保留应用数据，卸载重装会清空本机记录。

手机版课内词汇和词本保持紧凑行高，支持上下滚动；练习保留固定底部操作区。首页 Inspire 1–4 使用相同大小的入口和各自颜色的文字封面，尚未开放的教材显示锁定。右侧模式栏点击空白即可关闭。调整词本时可返回释义。释义、分享、导入和说明均以整页显示，各页面切换带过渡动画。设置分为学习、复习、资料和说明四页；“说明”提供简短图标手册。已会收录动画支持系统的减少动态效果偏好。

电脑版保留正常输入框和实体键盘输入，不显示内置键盘。手机键盘采用英语 QWERTY 排列，第二排错位排列；重音选项锚定原按键，滑动高亮、松手输入，滑出可取消。双击 Shift 锁定大写，长按删除连续删除。

错题复习

错题按累计错误次数从多到少排列；当天已复习的放在下方，当天不再进入错题练习。

每个词在错题本完整练完计一次复习，复习两次后可自动移出，也可以关闭移出选项保留。移出后，累计错误次数和复习次数仍保留。

复习本或错题本达到 10 个待练词显示红点，点击对应练习入口消除。有到期复习时每天最多发一次系统通知；错题仅在软件内每两天提醒。提醒不受10词红点门槛限制。通知权限可在系统通知设置中修改。

同一个词在每轮 5 词的学习中，选择、填空、重试或查看提示合计最多计错一次。

10. 口语模式

点击“模式”，在右侧栏选择“口语练习”。词汇学习可独立使用，不必先准备口语。

首次使用完成三步：

  1. 从 Release 下载 ggml-model-q5_0.bin（约 1.08 GB），在设置 → 口语 → 导入本地模型。校验结束后才可使用。
  2. 允许当前设备的麦克风权限。
  3. 点击“绑定小智”，复制应用实际显示的绑定码，打开小智控制台。登录自己的账号，创建“DELF A1 法语口语考官”，复制应用提供的考官配置，选择自己账号可用的模型和法语音色，再在控制台“添加设备”中输入绑定码并关联智能体。入口以控制台显示为准。返回后等待“考官已连接”。电脑和手机需分别绑定。

选择引导问答、信息交换或情景对话，也可以连续完成三个环节。点击“开始说话”，说完点击“我说完了”；识别在当前电脑或手机完成。识别成功后自动发送给考官并回复，不需要确认或修改文字。

模型下载完成后，本机识别可以离线运行。考官对话、法语语音回复及中文点评需要联网。实际权限、额度和费用按自己的小智账号和智能体配置执行。

结束练习后可查看中文点评、表达改写和建议。点评依据文字，不评价发音或口音，不是官方成绩。“记录”中可以回听并导出 ZIP，其中包含练习记录、识别文字、点评和本轮录音。

“口语设置”可查看模型与连接状态，导入或删除模型、重新连接、更换智能体、清除本机连接信息。删除模型会释放占用空间，保留学习记录、口语历史和绑定，之后可重新导入。平台解除绑定需在小智控制台设备管理中完成。

Windows 和安卓均单独导入法语识别模型，程序包不包含模型。Windows 完整解压后双击“启动启航法语.bat”，无需安装 Python、Node.js 或其他运行环境。更新保留原数据；安卓直接覆盖安装，勿先卸载。

词汇备份和口语导出分开管理。更换绑定不会自动清除历史记录；卸载前请分别导出需要保留的资料。

复习本按“已学习天数”从多到少排列；复习红点显示在首页入口和首页复习按钮，点击开始或继续复习后消除。

学满 30 天的词保留在复习本，进入每 30 天一次的长期复习；手动标为“已会”的词不再自动复习。

动词变位

导入动词时可选择原形和时态，默认原形与现在时。原形和变位分别练习；变位以三个动词原形为一组，先配对，再填空。Lesson 中各个人称变位有独立卡片。

在单词释义中点“查看变位”；变位练习中点“释义”，直接显示正在练的动词和时态。返回后继续原题。每日完成词数按人称形式分别计数，重复答题不会重复计入；分组和课次词数仍按动词原形。

逗号导入单词

首页 → 选择教材 → 导入本 → 选择 Lesson → 导入单词。用逗号隔开输入，例如 bonjour, un livre, hôtel，点击导入，匹配明确的词会直接导入；只有歧义、疑似拼写错误或未找到的词需要处理；使用系统普通键盘。先匹配完全一致的拼写，再识别大小写、重音、连字和少量拼写差异；出现多个候选时请选择。

导入本与 Inspire 教材并列，按导入顺序每 30 个单词自动分为一个 Lesson，不足 30 个也可学习。新词接着编入后续位置；已有课次不因移除单词而重新编号。每课先显示待学词，学过的词置后，导入日期以浅色小字显示。导入的单词同时显示在词本 → 全部本，重复导入保留原日期和进度。

“开始学习”先进入背诵卡片，再以 5 个词为一组练习。未完成时再次进入会继续原题；一组完成后可继续下一组。导入词学完后自动进入复习本；在释义页点“已会”后进入已会本，不再自动复习。“词本”中也可手动调整归属，导入本保留同一份学习进度。在导入本列表点击移除图标只移出导入本，保留全部本条目、复习安排和学习记录。

课内录音、课外单词及例句录音均已内置，点击即可离线播放，无需另下语音包。中文例句译文尚未覆盖全部条目；没有译文的例句显示法语。

词库来源和许可见设置帮助页及随程序提供的词库来源文件。词频筛选不代表官方 CEFR 分级。

复习日历与提醒

学习当天算第1天，正常复习固定在第2、4、7、15、30、60、90天，之后每30天一次。已完成第4天复习的词，第6天不会再次安排普通复习。未完成的到期词会作为逾期待复习保留，补做后仍按原来的日历继续。

开启“复习答错，次日加练”后，某天复习答错的词会在第二天增加一次练习。例如第7天答错，第8天加练，第15天的正常复习仍保留。答错和正确都不会把整个正常日历向后推。

安卓在设置 → 词汇 → 复习中允许系统通知和“准时提醒”。提醒由系统安排，正常退出应用后仍可触发；页面显示下一次安排及后台限制。收不到提醒时，点击“后台运行与自启动”和“省电限制设置”，允许启航法语后台运行；小米手机还需在系统应用设置中允许自启动。系统“强行停止”后须重新打开应用才能恢复；关机期间不能通知。Windows 版会设置当前用户的每日后台提醒，电脑关机或未登录时不会通知，打开应用后会检查未完成的复习。错题不会发送系统通知。

切换教材时，每本书分别保留上次选中的 Lesson；从预览返回不会改变当前选择。

口语首次配置

Windows 和安卓的识别模型均为独立下载文件。在同一下载页取得 ggml-model-q5_0.bin，打开设置 → 口语 → 导入本地模型，选择文件并等待完整性校验。无需填写路径或安装其他运行环境。模型通过校验后才能录音识别，首次准备语音引擎可能需要约一分钟。模型可在口语设置中删除，学习记录、口语历史和绑定会保留。

请选择下载页指定的 Q5 文件。其他格式或仅文件名相同的文件不能使用；导入时会核对固定文件大小和 SHA-256。
