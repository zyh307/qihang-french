# 变位资料与许可

法语变位器3.0的80个动词及三个时态继续使用原表格，包括 rendre、confondre 和已校正的 prenez。

补充的 -ir / -ïr 动词表依据 Pierre Sarrazin 的 [Verbiste 0.1.49 XML 源码](https://deb.debian.org/debian/pool/main/v/verbiste/verbiste_0.1.49.orig.tar.gz)，版权 © 2003–2016 Pierre Sarrazin，按 GPL-2.0-or-later 提供，本项目按 GPL-3.0 分发衍生数据。归档 SHA-256 为 `4a756133c0eba27b1a8e236dae53ae17325605ba486fe6cb2eb2be9966683fa5`。生成脚本 `scripts/build-ir-conjugations.py` 选取词库和教材已有的原形，展开现在时、未完成过去时和过去分词，补充复合过去时、代词式以及单独核对的个别形式。助动词使用各词条所选的常用用法。

第二组的判定参考 [OQLF](https://vitrinelinguistique.oqlf.gouv.qc.ca/24654/la-grammaire/le-verbe/conjugaison/verbes-reguliers-et-irreguliers)。个别形式参考法国 [法兰西学院词典](https://www.dictionnaire-academie.fr/) 和 [CNRTL](https://www.cnrtl.fr/definition/raidir)。
