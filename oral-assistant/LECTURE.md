# 读课文 · Lecture

服务首页选择「读课文」。主应用使用现有本机口语服务连接，重新生成口语静态资源后可见入口。课堂模式使用本机 Whisper；无需绑定小智。情景任务卡暂时隐藏，考试仍有独立入口。

## 安装一篇课文

内置的 8 篇 Inspire 1 原创主题课文可直接打开。下面的步骤只用于额外添加已获授权的教材原声课包。

在服务的 `.media/lecture/` 放一份 UTF-8 JSON 和对应教材原轨。音轨按三位 Piste 号命名（如 `073.wav`），格式为单声道 PCM16、16 kHz；保留原轨开头以保持时间坐标一致。已有音轨可以被多篇课文引用。该私有目录被 Git 忽略。

JSON 文件名等于 id。顶层字段为 schema、id、unit、lesson、title（fr、zh）、source、roles、piste、rate（normal、slow）、sentences。每句包含稳定 id、role、fr、zh、piste、start、end（原轨秒数）、difficult、variants。变体写整句，仅用于认可同一读法的转写差异。对话按角色分轮；独白使用旁白。整段播放范围为首句开始至末句结束。

## 切句与反馈

`lecture_alignment.split_turn(text, max_words=18)` 接收单一角色的话轮。问号、叹号、单个句号为边界。保留省略号与常见称谓缩写；较长句优先按逗号、冒号、分号拆分，超长而没有边界时提示人工标注。编写者还需对照真实音轨核实姓名、缩写、停顿和角色。正文每个切片应单独回放核对首尾。

`compare(sentence, asr)` 先检查语段证据。缺文本、缺语段、任一段平均对数概率低于 −1、无语音概率大于 0.60 时给待确认，两项分数为空。有效识别与原句及显式变体分别对齐，取准确率、覆盖率最高者。大小写和标点不参与，省音号按词边界处理，保留法语重音。相邻换序用动态规划，插删中移动的同词和互换的替换词再标记为词序差异。复杂错读可能有多种等价对齐。

覆盖率是有对应位置的参考词数除以参考词数；替换算覆盖但扣准确率。准确率为 1 减编辑罚分除以参考词数，最低为零。通过需覆盖率 ≥95%、准确率 ≥90%；边缘需 ≥75%、≥70%；其余建议重读。发音音素、连读音质及流利度未评分。

## 记录

会话数据在服务数据目录 `lecture/v1/sessions/<id>/`，每次录音另存 WAV。JSON 保存课文快照、队列、阶段、跳过和每次识别、对齐、评分。读取报告时取每句最近一次有足够证据的结果。边缘与重读加入本轮错句队列，通过后移出；无可靠识别仅标待确认。复盘可重开本轮错句。ZIP 包含记录 JSON 和学生录音，标准教材原轨单独安装。浏览器已支持导出，APK 原生保存及 ZIP 导入待验证或接入。备份恢复可在服务停止时将整个会话目录复制到另一台设备对应的空目录，并安装同版课文包。

开发自测在 oral-assistant 目录运行 `python -m unittest discover -s tests`。本机正式记录不能用于写入测试。
