# 单元口语 · Par unité

在本地口语服务首页打开「单元练习」，选 Unité 4。每卡先看场景，录一到两句法语，听回放、确认实际说的话，再看反馈。首页可以继续上次未完成的一轮。考试和单元有各自的历史列表。

## 运行与验证

沿用本项目的本机法语识别配置，在 `oral-assistant` 运行 `python launch.py`。主应用重新运行 `npm run dev` 会复制新版口语页面；连接更新后的本机 Python 服务才显示单元入口。安卓原生离线识别需要适配，此版本的联网试用网关不提供单元接口。

在本目录运行 `python -m unittest discover -s tests`。单项命令为 `python -m unittest discover -s tests -p test_unit_practice.py`。HTTP 测试在临时目录运行，覆盖三卡提交、重复请求、低把握转写确认、识别失败回听和再次作答。

## 增加一个单元

复制 [U4 完整练习包](units/inspire1-u4.json)，以稳定 ID 命名 JSON 文件。填写相同的 id、schema、unit、双语 theme、3–5 个 targets、10–15 项 vocabulary 和 3–5 张 cards。使用不重复的卡 ID。词汇是本单元的主动表达目标，每张卡按交流任务选用。retell 用于串讲。

每卡的 prompt 说明角色和任务，hint 给思路，starter 给半句，model 是可模仿的完整回答，variants 给出可接受的其他说法。criteria 每项由一个反馈标签和若干等价表达组成。确认文本经大小写、重音和标点归一化，命中任一等价表达便满足该项。新包应逐卡检查参考句与变体，并人工检查容易误收的反例。U4 参考例句为围绕教材目标原创的练习，其他单元需要先核对课次及目标。

## 判定与记录

所有要点命中为通过，部分命中为边缘，全部缺失为建议重试。反馈写「已表达」「可以补充」并给示范。识别语段的平均对数概率和无语音概率只提示核对；学生确认前不会写成绩。时长和句数不作为硬性给分条件。再次录音、再次作答均保留先前尝试。

单元记录位于服务数据目录的 `unit-practice/v1/sessions/<id>/`。其中 session.json 以原子替换保存任务快照、原始及确认文本、反馈、WAV 引用和历史尝试，录音是 16 kHz 单声道 PCM。关闭练习并停止该服务后，可复制整个 `unit-practice/v1` 到新设备同一位置的空目录。两个非空目录合并与 ZIP 导入导出留待迁移里程碑。

复盘按识别语段累计秒数除以从创建到末卡确认的总时间，含读卡、识别等待和中途离开的时间。缺失语段统计时不显示比例。培训目标为连续真人练习中学生开口超过全轮一半；验收用人工标注的说话时间核对近似指标。
