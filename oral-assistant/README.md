# DELF A1 法语语音助手

启航法语的独立口语练习模块。在浏览器中录音，由本机法语识别模型转成文字，再交给小智考官生成法语语音回复。当前聚焦 DELF A1，后续可在此基础上扩展 A2、B1、B2。

本模块可独立运行，尚未接入主项目 Vue / Android 界面，也没有在线公共服务器。GitHub 下载源码与实际口语对话服务是不同的入口。

## 当前功能

| 模块 | 已实现内容 |
| --- | --- |
| 引导问答 | 14类主题、42个预设问句；每次随机顺序和问法，根据已聊内容继续追问 |
| 信息交换 | 48张词卡、8组主题；每轮抽6张不同主题的卡，由考生向考官提问 |
| 情景对话 | 12个场景，含角色、价格、时间、数量和交流目标；可随机或指定 |
| 陪练与模拟 | 三部分单独练习或完整练习；完整模拟有10分钟准备时间，参考计时不硬切录音 |
| 识别与录音 | 独立法语识别、可选回复前确认、原声回听、麦克风电平和设备选择 |
| AI复盘 | 结束后按实际发言给中文点评、原句改写和练习建议；可重试和重新生成 |
| 练习记录 | 对话、原始录音、识别、确认文字、事后修订和历次评价分别保存；可导出文字 |

当前为按键录音：点击“开始说话”，讲完点“我说完了”，等待考官回复。尚未实现全双工抢话或自动连续收音。AI复盘基于文字，暂不评发音，不作为官方考试成绩。

## 安装与启动

需要 Python 3.12、可访问小智服务的网络和浏览器麦克风权限。独立识别还需要自行下载约3.1 GB的法语模型；GPU可降低延迟，CPU也可运行，但速度取决于设备。

在仓库根目录打开 PowerShell：

```powershell
cd oral-assistant
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
.\.venv\Scripts\python.exe -m pip install --target .whisper_deps -r requirements-french.txt
.\.venv\Scripts\python.exe scripts/prepare_model.py --french
.\.venv\Scripts\python.exe launch.py
```

浏览器打开 **http://127.0.0.1:8127/**。安装完成后，Windows 可双击 `启动口语助手.cmd`；优先使用模块内的 `.venv`，也可通过 `QIHANG_ORAL_PYTHON` 指定Python路径。

有兼容NVIDIA显卡时，可另外安装已经在原开发环境验证的Windows依赖：

```powershell
.\.venv\Scripts\python.exe -m pip install --target .gpu_deps -r requirements-french-gpu.txt
```

不同硬件和驱动仍需实测。CPU运行可在首次启动生成的 `.speech/engine.json` 中设 `{"device":"cpu"}`，之后在无练习时重启自己的识别服务。

macOS / Linux使用 `python3.12 -m venv .venv` 与 `.venv/bin/python` 执行同样的安装、模型下载和 `launch.py` 命令；本次公开导出在Windows自测，不承诺其他系统的GPU配置已验证。

### 模型与下载

- 模型：[bofenghuang/whisper-large-v3-french](https://huggingface.co/bofenghuang/whisper-large-v3-french)，固定提交 `90a7cd1fea9cd69f80f5a0fc49738418dba96083`，CTranslate2格式，固定法语识别。
- 默认下载到 `.models/whisper-large-v3-french/ctranslate2/`。下载器校验固定提交下的文件大小和摘要，不上传任何用户录音。
- 如确有需要，可在下载命令追加 `--mirror`；代理只在当前下载终端设置 `HTTP_PROXY` / `HTTPS_PROXY`。本机语音识别请求不会经过下载代理。
- 仓库不包含模型、CUDA库、安装环境或维护者电脑上的现成配置。

### 连接小智

1. 在自己的小智控制台创建一个智能体，参考 [角色配置](docs/角色配置.md)，选择法语音色。
2. 打开本模块网页，点“连接小智”。
3. 把页面给出的新绑定码填入控制台“添加设备”，关联到刚创建的智能体。
4. 绑定就绪后开始练习。每台安装有自己新生成的身份，切勿向别人索取、复制或上传维护者的identity文件。

小智的服务可用性、账户权限、用量及音色取决于平台。源码开源不等于托管服务永久免费或一直在线。

### 只测试界面和协议

不下载大模型、也不连接小智即可运行隔离替身：

```powershell
.\.venv\Scripts\python.exe tests/run_fake.py
```

然后打开 http://127.0.0.1:8137/ 。这是测试替身，回复和识别文字是模拟数据，不能用来判断真实法语识别准确度。

## 数据边界与当前限制

- 个人记录位于 `.local/sessions/`；独立识别只在本机处理原声，识别文字和任务交给小智生成回复与评价。选择旧版“小智原有识别”时，录音也会传给小智。
- 原始转写、回复前确认、事后修订和AI评价分别保留。AI评价核对原句引用，但语法点评仍可能有误。
- 服务默认仅监听127.0.0.1；8132为受凭证保护的识别工作进程，浏览器访问个人端口8127。不能把127.0.0.1发给另一台设备使用。
- 同一实例一次一人练习；身份共享、多账号、排队和正式服务器部署仍待开发。
- `trial_server.py`及团队脚本保留为实验功能。团队脚本需要自行配置经校验的Cloudflared工具，默认不会启动公网隧道，详见 [开发说明](docs/开发说明.md)。
- 如8127或8132已有另一个实例，先结束对应实例的练习并处理端口冲突；不要批量终止Python进程。

## 开发自测

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

测试仅使用临时目录、独立端口和模型替身，不读取维护者的正式学习记录，不调用真实小智。公开版的示范视频缺省行为与本地视频Range路径均有隔离测试。
