# 启航法语 2.0 口语服务接入

主应用从右侧模式栏切换口语和词汇。手机只运行界面与录音，识别模型及小智连接运行在口语服务上；已有 Python 安装、模型准备及小智绑定步骤见模块 README。

服务默认仅允许本机浏览器。仅在准备好受信任的 HTTPS 反向代理后，为个人设备启用接入：

```
python scripts/configure_app_client.py --host oral.example.com
```

命令在 `.local/private/app-client.json` 生成本机独立访问码，并列出填写到主应用的服务地址和访问码。该文件属于私有运行配置，不提交 Git。配置已存在时不会覆盖访问码。

服务仍默认监听 `127.0.0.1:8127`。反向代理需保留 Host 与 Origin，转发 `/api/`、`/examples/` 和 `/ws`，支持 WebSocket 升级；对公网仅提供 HTTPS。除安卓的应用内来源外，默认允许本机主应用的 5192 和 5193 端口；新增网页来源使用 `--origin https://your-app.example.com`。

HTTP 使用 Bearer 访问码；WebSocket 在子协议中提交访问码，只回显普通协议名。仅允许配置中的来源与服务主机，不使用通配 CORS，不把访问码放进链接、学习备份或日志。每个服务实例仍一次一人练习；不要把个人服务作为没有隔离的公共多人服务器。

前端资源由 `scripts/build-oral.mjs` 从本模块生成，统一使用主应用配色。独立浏览器入口保持可用；源分支和贡献者历史随合并保留。
