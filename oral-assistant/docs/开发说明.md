# 开发接入说明

## 结构

```text
浏览器录音与回听
  → Python Web服务 server.py
  → 本机受鉴权的法语ASR speech_server.py
  → 小智托管考官 hosted.py
  → 法语语音回复
  → 结束后的文字评价 evaluation.py
```

| 文件 | 职责 |
| --- | --- |
| web/ | 独立HTML、CSS、JS前端，录音、PCM播放、题卡和复盘界面 |
| server.py | 同源HTTP / WebSocket、练习状态、录音保存与小智桥接 |
| hosted.py / mcp_tools.py | 每台安装身份、激活、语音通道和只读任务工具 |
| question_bank.py / exam.py / flow.py | 题库、会话题卡快照、已谈主题、词卡进度、参考计时与收尾 |
| french_asr.py / speech_server.py / speech_service.py | 本机Whisper推理、受鉴权工作进程及复用 |
| evaluation.py | 原话证据、结构化评价、失败重试、历史评价保留 |
| store.py | JSON文件原子保存，保留原始识别、确认及修订 |
| trial_server.py | 实验团队入口的访客Cookie、归属检查和单人试用名额 |

## 与主项目结合

当前只在主README添加源码入口，保留为独立服务。主项目继续通过Node / Vue启动，不因本模块新增Python运行依赖。下一步可先在桌面端添加一个显式的口语入口，再设计账号、权限、学习档案同步和服务器部署。

网页当前使用同源 `/api/…` 与 `/ws`，仅把静态文件复制进Vue或GitHub Pages不能运行。接入独立域名时，需要完整处理HTTPS、WebSocket、来源校验、用户鉴权与录音归属；不要把本机绑定密钥放进前端。

## 验证边界

单元／集成测试只用临时目录和替身，不下载模型、不联系托管考官；本次公开版补充不含视频时的说明与直接练习路径。没有将个人正式身份或原声复制进测试。

真实麦克风、不同口音、完整模型推理、托管模型行为与外网移动端仍需单独联调。开发自测不等于DeepSeek独立验收或正式官方评分校准。
